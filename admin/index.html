記事の探し方

上の欄に記事名やURLの一部を入れると、その記事だけが開いた状態で表示されます。.note の記事は「分野 → グループ → 項目」の順に入っているため、探すときは検索が確実です。

下書きの扱い

編集した内容はこのブラウザに自動保存されます。プレビューでは下書きが優先表示され、実際のサイトには「GitHubへ公開」するまで反映されません。

GitHubへ公開

変更した JSON を GitHub リポジトリへコミットします。GitHub Pages が再ビルドされ、数十秒〜数分でサイトに反映されます。

HTMLを書き出す

編集中の内容を埋め込んだ完成HTMLを作り、ZIPでダウンロードします。
